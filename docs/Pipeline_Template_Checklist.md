# 流水线模版功能检查清单

## 1. 新增模版功能

### 1.1 基本信息
- [ ] 模版名称（必填）
- [ ] 模版编码（必填，唯一）
- [ ] 模版类型（CI/CD，必选）
- [ ] 编程语言（必选）
- [ ] 语言版本（可选）
- [ ] 框架（可选）
- [ ] 描述（可选）
- [ ] 官方模版（开关）
- [ ] 状态（启用/禁用）

### 1.2 初始版本信息
- [ ] 版本号（默认 1.0.0）
- [ ] Jenkinsfile 内容（必填，有默认模版）
- [ ] 变更日志（默认"初始版本"）
- [ ] 设为最新版本（默认勾选）

### 1.3 默认模版
- [ ] Java CI 模版（包含 Checkout、Build、Test、Build Image）
- [ ] Node.js CI 模版（包含 Checkout、Install、Build、Test、Build Image）
- [ ] CD 模版（包含 Deploy、Health Check）

### 1.4 验证规则
- [ ] 模版名称不能为空
- [ ] 模版编码不能为空
- [ ] 模版编码唯一性检查
- [ ] 模版类型必选
- [ ] 编程语言必选

## 测试步骤

### 测试 1：创建模版
1. 点击"创建模板"
2. 填写基本信息
3. 查看默认 Jenkinsfile 内容
4. 点击确定
5. 验证：模版列表中出现新模版

### 测试 2：编辑模版
1. 点击某个模版的"编辑"
2. 修改名称
3. 点击确定
4. 验证：模版名称已更新

### 测试 3：版本管理
1. 点击"版本管理"
2. 查看版本列表
3. 点击"创建新版本"
4. 输入版本号和内容
5. 点击创建
6. 验证：版本列表中出现新版本

### 测试 4：编辑内容
1. 进入版本管理
2. 点击"编辑内容"
3. 修改 Jenkinsfile
4. 点击确定
5. 点击"查看内容"验证

### 测试 5：自动迭代
1. 进入版本管理
2. 点击"自动迭代"
3. 确认对话框
4. 验证：新版本号自动递增

### 测试 6：编辑阶段
1. 进入版本管理
2. 点击"编辑阶段"
3. 选择阶段
4. 修改脚本
5. 点击确定
6. 验证：阶段脚本已更新

### 测试 7：复制模版
1. 点击"复制"
2. 验证：新模版编码为 {原编码}_copy
3. 验证：版本号为 1.0.0
4. 验证：内容与原模版一致

### 测试 8：导出导入
1. 点击"导出"
2. 打开 JSON 文件，检查内容
3. 修改 code 字段
4. 点击"导入模板"
5. 选择 JSON 文件
6. 验证：新模版创建成功

### 测试 9：删除模版
1. 点击"删除"
2. 确认对话框
3. 验证：模版从列表中消失

### 测试 10：搜索筛选
1. 选择模版类型"CI"
2. 验证：只显示 CI 模版
3. 输入模版名称搜索
4. 验证：显示匹配的模版
