## 问题概述

新增应用时，选择所属项目后，所属模块的下拉选项无法加载。

## 问题原因

`ApiSelect` 组件的 `api` 函数已经返回数组格式数据（`result.items || []`），但同时设置了 `resultField: 'items'`，导致组件尝试从数组中提取 `items` 属性，得到 `undefined`。

## 修复方案

移除模块字段配置中多余的 `resultField: 'items'`，因为 `api` 函数已经返回数组。

## 修复内容

修改文件：`web/apps/web-antd/src/views/release/application/data.ts`

**当前问题代码（第 42-60 行）：**

```typescript
componentProps: {
  api: async (params: any) => {
    if (params?.project) {
      const result = await getModuleList({ project: params.project, status: 1, page_size: 1000 });
      return result.items || [];  // 已经返回数组
    }
    return [];
  },
  resultField: 'items',  // 多余！会导致从数组中找 items 属性
  // ...
}
```

**修复后：**
移除 `resultField: 'items'`，保留 `labelField` 和 `valueField`。

## ApiComponent 工作原理

- 监听 `mergedParams`（= `props.params` + `innerParams`）变化
- `dependencies.componentProps` 返回 `{ params: { project: values.project } }` 会更新 `props.params`
- `mergedParams` 变化触发 `fetchApi()` 重新加载
- `api(params)` 接收更新后的 params 参数
