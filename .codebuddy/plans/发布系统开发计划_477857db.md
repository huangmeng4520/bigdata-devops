## 产品概述

基于 Django5 + Vue3(vben-admin) 技术栈，开发发布管理系统，实现项目→模块→应用三层结构的CI/CD资源管理。

## 核心功能

- **项目管理**：项目CRUD、项目列表、统计信息展示
- **模块管理**：模块CRUD、关联项目、模块列表
- **应用管理**：应用CRUD、关联模块和项目、应用类型管理
- **配置包管理**：配置包生成、列表查询、下载功能
- **同步日志**：日志列表、日志详情查询

## 三层业务架构

```
项目(Project) → 模块(Module) → 应用(Application)
```

## 技术约束

- 后端模型必须继承 `utils.models.CoreModel`
- ViewSet必须继承 `utils.custom_model_viewSet.CustomModelViewSet`
- 序列化器使用 `utils.serializers.CustomModelSerializer`
- 权限码格式: `release:{model}:{action}`
- API路由前缀: `/api/admin/release/`

## 技术栈

### 后端

- **框架**: Django 5.2.1 + Django REST Framework 3.16.0
- **数据库**: MySQL (django_vue)
- **缓存**: Redis
- **异步任务**: Celery

### 前端

- **框架**: Vue3 + Vite + TypeScript
- **UI组件**: vben-admin + Ant Design Vue
- **表格组件**: VxeTable

## 实现方案

### 后端架构

采用与 `system` 模块相同的架构模式：

1. 创建 `backend/release/` Django应用
2. 模型层：6张核心表（Project、Module、Application、ConfigPackage、SyncLog、Template）
3. 序列化器：继承 `CustomModelSerializer`，支持审计字段自动填充
4. 视图层：继承 `CustomModelViewSet`，支持软删除、权限控制、分页
5. 路由：使用 `DefaultRouter` 注册ViewSet

### 前端架构

采用与 `system/dept` 模块相同的架构模式：

1. API层：`src/api/release/` 目录，定义TypeScript类型和API方法
2. 页面层：`src/views/release/` 目录，包含列表、表单组件
3. 使用 VxeTable 表格组件，支持树形展开（项目→模块→应用）

## 数据模型设计

### 核心表结构

| 表名 | 说明 | 关键字段 |
| --- | --- | --- |
| release_project | 发布项目 | name, code, gitlab_group_id, status |
| release_module | 发布模块 | project_id, name, code, gitlab_subgroup_id |
| release_application | 发布应用 | module_id, project_id, name, code, app_type, git_url |
| release_config_package | 配置包 | app_id, version, file_path, sync_status |
| release_sync_log | 同步日志 | config_package_id, sync_type, action, status |
| release_template | 发布模板 | name, code, template_type, content |


### 模型继承关系

所有模型继承 `utils.models.CoreModel`，自动包含：

- remark: 备注
- creator: 创建人
- modifier: 修改人
- create_time: 创建时间
- update_time: 更新时间
- is_deleted: 软删除标记

## 性能考虑

1. 使用 `select_related` 优化外键查询（Project→Module→Application）
2. 使用 `prefetch_related` 优化反向查询
3. 列表API支持分页，避免全量查询
4. 前端使用虚拟滚动处理大数据量表格

## Agent Extensions

### SubAgent

- **前端工程师**
- Purpose: 开发前端页面组件、API接口定义
- Expected outcome: 完成项目管理、模块管理、应用管理三个核心页面的前端开发

- **code-explorer**
- Purpose: 探索现有代码模式和架构规范
- Expected outcome: 确保新代码与现有架构完全一致
